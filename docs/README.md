## 维护约定

1. **登记制**：文档与索引同步变更，不允许"孤儿文档"。
2. **冲突优先级**：`AGENT.md` > ADR > 白皮书 > 功能/体验规格 > 指南；发现冲突先修正低优先级方。
3. **目录变更**：新增顶层目录需项目所有者确认；现有目录不得随意移动（会破坏链接）。
4. **状态标注**：除入口文件外，每份文档头部含"状态/维护者/最后更新"三元组（`AGENT.md` §4.1）。
5. **ADR 历史不可改写**：修订 = 新 ADR supersede，而非编辑旧文。
