# ADR-0016：检索原生 vision token 模型训练路线与自监督生长愿景

- 状态：Proposed（2026-09-11 所有者构想与多轮讨论：知识锚点、CLIP 偏移质疑、DeepSeek-OCR
  压缩猜想、visual anchoring 撤回论文追踪；文档状态待所有者追认）
- 日期：2026-09-11
- 决策者：项目所有者（构想发起）
- 相关：ADR-0015（区域级语义索引，前置依赖）、ADR-0013（多索引）、ADR-0010（Chinese-CLIP）；
  文献：ColPali/ColBERT（late interaction）、DeepSeek-OCR（arXiv:2510.18234）、
  visual anchoring（DeepSeek 2026 撤回论文）、WIT（SIGIR 2021）、OVEN（2023）、
  External Guidance（ICML 2024）、SCALE（AAAI 2023）

## 背景

ADR-0015 定案的检索级联中，「patch-MaxSim 精排」实测较单向量余弦 hit@10 ×2.3
（DINOv2 patch token, 224 输入 256 patch ≈ 300 token 量级）。但当前 patch token 来自
DINOv2——**其 token 空间无文本对齐**：语义检索仍依赖 CLIP 单向量粗排，晚交互的细粒度
增益无法兑现到文本查询。

DeepSeek-OCR 证明 vision token 可作为高保真压缩上下文（100 token ↔ 1000 文本 token,
97%），但其 token 语义存在于自身 LLM decoder 隐空间——直接拿来做检索存在跨空间投影
门槛。DeepSeek 撤回的 visual anchoring 论文（视觉锚定 = 空间推理底层机制）与
V4-Flash-Vision-Exp（2026-08 开源，MIT）确认该方向的战略价值。

所有者进一步追问：能否让模型**从少量算力中自己长出智能，只需很小的对齐就与人类世界
对接**？（自监督生长；对齐最小化。）

## 决策

### 1. 训练检索原生 vision token 模型（「自己造隐空间」）

- **架构**：视觉塔（DINOv2 ViT-S 或 Chinese-CLIP 视觉塔）→ patch token（256）
  → 轻量适配层；文本塔（Chinese-CLIP BERT）→ query token；
- **训练目标**：late-interaction InfoNCE——batch 内正负对 (query token set, patch token set)
  的 MaxSim 对比损失。**token 隐空间从出生即对齐检索**，消掉跨空间投影门槛
  （DeepSeek-OCR token 需要「token→检索空间」投影；本路线从源头不需要）；
- **算力**：LoRA 级别，4070 8GB（数小时~数天/轮）；基座权重全开源。

### 2. 数据三级火箭（鸡生蛋的解法）

1. **冷启动（零人工）**：开源 VLM（Qwen2.5-VL-3B / DeepSeek-V4-Flash-Vision-Exp，MIT）
   为 5142 个已验证区域生成自由描述（「正在奔跑的狗」粒度）→ LLM 从描述合成查询文本
   → 数万对训练数据；
2. **微调**：LoRA 注入 late-interaction 目标；架构约束沿用 ADR-0015 定案
   （256 token、MaxSim、PCA 签名粗排）；
3. **飞轮**：搜索点击日志 = 免费个性化训练对（正例=点击，hard negative=跳过的候选）。

### 3. 自监督生长愿景（对齐最小化，长期）

相册流 = 天然具身自监督数据流，四个免费监督信号：视觉（DINO 已实证）、
时间（EXIF 对比学习：同段互为正例）、空间（GPS 原型 = 「地点概念」涌现）、
结构（频域去重）。**对齐最小化指标：每个新概念需要用户几次指认才能被正确检索
（目标 ≤3 次；对照：全网先验方案 = 0 次但无个性化，纯自监督 = ∞ 次）。**
知识锚点（ADR-0015 §5）即稀疏指认接口——认知对应：儿童几十次指认锚定概念，
因为自监督表征已把狗聚成一团，标签只是贴名字（DINO 线性探针 80%+ 为实证）。

### 4. 分体架构（诚实边界）

语言推理与世界因果知识无法从个人相册涌现（文化传输产物，非个人数据可学）。
架构分体：**自监督小模型 = 视觉皮层 + 海马体**（自己看出来的类、自己的地点、
自己的时间线）；**外部大模型 = 语言皮层**（世界知识、推理、命名）；接口 = 薄对齐
（锚点词表 + 线性投影）。

## 后果

### 积极

- 检索隐空间原生对齐（消跨空间投影），细粒度晚交互增益可兑现到文本查询；
- 中文域 + 个人相册分布适配（LoRA 个性化）；数据飞轮闭环（点击→训练→更准）；
- 自监督生长愿景有明确度量（每概念指认次数），项目获得「个人具身智能最小对齐
  实验场」的研究叙事。

### 消极 / 需关注

- 评测集必须先行（查询→正确照片金标 ≥200 条，否则训练不可评估）；
- 合成数据偏差（VLM 描述的有损性与幻觉）；过拟合风险（个人数据集小，需 LoRA 小步 + 基线对照）；
- 基线固化（CLIP 0.653 / PCA-64 0.639 / DINO MaxSim ×2.3）不打赢不替换。

## 备选方案

| 方案 | 结论 | 原因 |
| :--- | :--- | :--- |
| DeepSeek-OCR vision token 直接检索 | 暂缓 | 跨空间投影训练不可避免，绕不开；等其投影生态 |
| V4-Flash-Vision-Exp 视觉头 + 投影头 | 观察 | 表示最强但 Exp 生态不成熟（vLLM 316 tensors 报错）；成熟后为投影头最佳底座 |
| 从零预训练 CLIP/VLM | 永久否决 | 算力/数据超个人量级九个数量级以上 |
| 纯锚点分类（词表即簇） | 限定用途 | zero-shot 分类，聚类感丧失（所有者 2026-09-11 裁定）；仅用于命名与浏览 |
