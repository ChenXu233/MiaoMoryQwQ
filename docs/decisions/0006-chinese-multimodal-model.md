# ADR-0006：中文图文模型硬约束

- 状态：Accepted
- 日期：2026-09-04
- 决策者：项目所有者
- 相关：白皮书 §1.3、§3.4

## 背景

CLIP ViT-B/32 的文本编码器为英文主导，中文查询命中质量明显下降。产品体验哲学明确"中文母语检索是硬约束"。

## 决策

我们决定：

1. **MVP 语义模型必须原生支持中文查询**；CLIP ViT-B/32 仅作英文基线，不作为交付模型。
2. 候选池：jina-clip-v2、BGE-Visualized-M3、Chinese-CLIP（排序不代表偏好）。
3. **一次性基准选型**（ADR-0004）：用项目所有者提供的中文查询集度量 top-k 命中率、单 query 文本编码延迟、批量图片吞吐、INT8 量化后体积、许可证。
4. 结果落新 ADR 记录选定模型；模型随应用版本锁定，换模型需重验并给出索引重建迁移策略。
5. 回退方案：英文模型 + 查询翻译层（仅当三个候选均不达标）。

## 后果

### 积极

- 中文体验有底线，选型有数据支撑
- 模型下载、版本、量化策略统一由 `crates/embed` 管理

### 消极 / 需关注

- 候选模型体积/精度未知，基准需人工准备查询集
- 模型许可证（含随包分发条款）需与选型一并确认

## 备选方案

| 方案 | 结论 | 原因 |
| :--- | :--- | :--- |
| 坚持 CLIP ViT-B/32 | 否 | 中文查询质量差，违反体验哲学 |
| 直接选定某一中文模型 | 否 | 无数据支撑的选型不可接受 |
