# ADR-0015：区域级语义索引（自然区域分离 → 多签名 → 原型空间 → 晚交互检索）

- 状态：Proposed（2026-09-11 所有者发起构想并批准原型实验，七轮实验完成；文档状态待所有者追认）
- 日期：2026-09-11
- 决策者：项目所有者（构想发起与多轮方向裁定：分层映射、双空间共识、时空调制、知识锚点、层级多轴、晚交互）
- 相关：ADR-0010（Chinese-CLIP）、ADR-0013（可插拔多索引）、ADR-0014（推理后端）；`experiments/region-proto/`（七轮实验代码与数据，提交 9b78369→3ba0d56）

## 背景

整图单向量索引（现用 Chinese-CLIP ViT-B/16 int8，512 维）存在结构性极限：

1. **单向量瓶颈**：512 维要压缩整图全部语义，局部细节（图中小字、角落物体）被稀释；
2. **相似度窄带**：图文余弦挤在 0.30~0.45 区间（实测），绝对值无语义、跨查询不可比，
   且无阈值可用（纯度实验详见 ADR-0010 后续讨论与 `experiments/region-proto/README.md`）；
3. **簇边界模型偏置**：DINOv2（纯自监督无文本对齐）独立聚类与 CLIP 聚类 NMI 仅 0.498——
   粗类是数据固有的，细边界带模型偏置，需要多特征交叉印证。

所有者构想（2026-09-11）：自然区域分离 → 区域 embedding → 跨库全局聚类（自然语义类）→
区域级晚交互检索。七轮原型实验（`experiments/region-proto/README.md`）已逐环验证并裁决分叉。

## 决策

### 1. 表示层：SAM 类分割 + 区域 CLIP 编码 + 低秩签名

- 分割：MobileSAM/EfficientViT-SAM 类全图分割（1600px 降采样图上跑，bbox 映射回原图裁剪）；
  过滤窗：面积 0.08%~85%，每图上限 40 区域（实测 22.6 区域/图）；
- 编码：区域裁剪（bbox+12% padding）过 Chinese-CLIP 图像塔（复用 int8 权重），512 维 L2 归一；
- **重叠合并**：mask NIOU>0.8 的区域共享 embedding（CLIP 调用次数 −30~50%）；
- **签名**：pooled 向量 PCA→64 维（压缩 8 倍，聚类/存储/检索全在签名上；实测纯度 0.827 反超全量）。

### 2. 聚类层：时空调制在线 DP-means（原型空间，非固定 K、非单树）

- **在线准入**：新区域距最近原型（1−cos）> τ_eff → 诞生新原型（即时可检索）；
  否则加权均值漂移（学习率 1/count）；
- **时空调制**（所有者 2×2 矩阵，EXIF 时间 + GPS）：连拍（Δt<5min 且 Δs<200m）τ×0.5；
  久留（同地）×0.9；移动（Δt<2h 且 Δs≥1km）×1.3；篇章（Δt>14d 且 Δs≥5km）完全新增独立原型集；
  实测 K 随时空覆盖响应（63→385），K(N) 为生活事件驱动的「平台+跳跃」阶梯；
- **周期维护**：mini-batch DP-means 全量重排（归属迁移，向量永不重算）+ 衰退合并
  （低权重老原型并入最近邻）；新簇「存活确认」（2 张内复现才转正）；
- **工作点**：τ_base≈0.24（标定区间 0.22~0.26，目标单例率 <25%）；
- **非目标**：不做单一大树——多轴 facet（见 3）。

### 3. 多轴 facet（非树状，已实证）

每区域持有六轴坐标，各轴独立粗细两层聚类，任一轴切片穿过其他轴几乎所有簇
（实测颜色轴 6 切片各横跨 34~47/48 语义细簇）：

| 轴 | 特征（成本） | 粗层 | 细层 |
|---|---|---|---|
| 语义 | CLIP 区域向量（贵，去重后一次） | DP-means 原型 | τ 细分 |
| 视觉 | DINOv2 patch pooled（中） | 同上结构 | 无文本偏置「纯粹聚类」轴 |
| 结构 | 频域签名（免费） | —— | 去重/连拍分组/实例近邻 |
| 时间 | EXIF（免费） | 篇章 | 时刻 |
| 空间 | GPS（免费） | 地点概念涌现 | 聚类 |
| 颜色 | 颜色矩（免费） | —— | —— |

### 4. 检索层：级联（便宜→昂贵，逐级收窄）

```
PCA-64 签名粗排（全库，余弦，top-C≈500）
→ patch-MaxSim 精排（候选内，256 token 晚交互；实测较余弦精排 hit@10 ×2.3）
→ （远期）VLM cross-encoder 终审（候选 ≤20）
```

### 5. 命名：知识锚点（向导，非路由）

中文 Wikipedia 视觉概念词条（标题+首段，分类树剪枝）编码为锚点库 → 簇命名与浏览入口
（原型抽查：天空 80% 正确、窗户全对）。知识锚点**不承担检索路由**（结构→语义路由已被
否决：NMI 0.18），错误命名由用户直接修正词表。数据驱动 DP-means 残差兜底（锚点未覆盖
的语义仍可成簇）。

### 6. 存储 schema（ADR-0013 框架内新增）

- `vec_regions`：vec0 表（index_id 维度隔离沿用 index_meta），键 (asset_id, region_id)，
  embedding float[512]；
- `region_meta`：region_id, asset_id, bbox, area_frac, cluster_id(各轴各层)；
- `region_clusters`：index_id, cluster_id, prototype[512], member_count, chapter_id；
- 命名沿用 index_meta 注册表：新索引 slug `sam-region-chinese-clip-vit-b16`，**与现有
  vec_assets 整图索引并存**（A/B 对比，不破坏既有检索）。

### 7. 性能预算（移动端目标）

- 提取：EfficientViT-SAM 类轻量分割 + 1024 输入 + 双线程流水 → 目标 ~2s/张（CPU）；
  现状 MobileSAM CPU 12s/张（原型值，未优化）；
- 存储：22.6 区域/图 × 512 f32 → PCA-64 后 22.6×256B ≈ 5.8KB/图（万张 ≈ 58MB）；
- 检索：签名粗排暴力 KNN（万张毫秒级），MaxSim 仅对 top-C 候选（算力常数可控）。

## 后果

### 积极

- 细粒度语义可检索（局部、区域级查询）；相似度区分度结构性改善（区域级匹配天然拉开窄带）；
- 簇自带名字与浏览维度（知识锚点），可解释、可增量（新词条=新簇）、错误可由用户修词表反馈；
- 增量成本 = 新照片的提取 + O(K) 准入，重排分钟级后台；向量一次性，永不重算；
- 多轴 facet 与 ADR-0013 多索引逐轴同构，DINO 轴预留「无文本偏置纯粹聚类」演进位。

### 消极 / 需关注

- 分割+编码为新的计算热点（导入后耗时增加），需错峰与进度卡复用（EmbedCard 模式）；
- schema 与查询路径复杂度上升（region 级联）；碎片管理（衰退合并）需要长期观测；
- SAM/CLIP 双权重分发体积增加；τ/乘数参数依赖实测标定（网格扫描脚本已备）。

## 备选方案

| 方案 | 结论 | 原因 |
| :--- | :--- | :--- |
| 维持整图单向量 | 保留（并存） | 粗检索主力；细粒度不足（窄带实证） |
| 频域结构空间做语义路由 | **否决** | NMI 0.18 ≈ 随机，结构/语义近乎正交 |
| 频域候选池 + 语义代表（−96% CLIP 调用） | 否决（单独） | hit@10 0.147，召回损失 77% 不值 96% 成本 |
| 固定 K k-means | 否决 | K(N) 为生活事件驱动阶梯，固定 K 必然不够/过碎 |
| DINO 单轴底座（替代 CLIP） | 转为并存轴 | NMI 0.498：粗类一致可互证，细边界各带偏置；DINO 无文本检索能力需另训 |
| 直接采用 DeepSeek-OCR vision token 做检索 | 暂缓 | token 语义在其 decoder 隐空间，检索需跨空间投影训练；「检索原生」路线见 ADR-0016 |
| V4-Flash-Vision-Exp 视觉头直接当索引 | 否决（零训练形态） | 输入嵌入空间无检索几何；「视觉头+投影头」半训练与 cross-encoder 终审两姿势保留 |
