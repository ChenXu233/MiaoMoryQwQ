# ADR-0003：MVP 范围——桌面优先

- 状态：Accepted
- 日期：2026-09-04
- 决策者：项目所有者
- 相关：白皮书 §2、§7

## 背景

v0.1 白皮书同时包含移动端、多存储后端、人脸识别、插件系统等目标，交付面过大，会稀释"桌面 + 中文语义搜索"这一核心体验。

## 决策

我们决定 MVP 收敛为**桌面 + 照片 + 中文语义搜索**：

- **IN**：桌面单二进制（Win/macOS/Linux）；照片导入（JPEG/PNG/WebP/HEIC）；SHA-256 增量去重；缩略图与时间轴/网格浏览 + Lightbox；中文图文语义搜索；元数据过滤；FTS5；RRF 融合；导入进度（可暂停/恢复/错误隔离）；模型下载（断点续传/离线提示）；自动更新器；键盘操作与基础无障碍。
- **OUT**：移动端交付、S3/PostgreSQL、人脸识别、插件/MCP、音视频语义索引、OCR、多窗口。
- **LATER**：OUT 各项及多语言 UI、位置搜索、收藏相册、分享导出。
- 架构不锁死移动端：core 无桌面假设、UI 响应式 token、移动端入口属性预留（白皮书 §7）。

## 后果

### 积极

- 交付面收敛到一条体验主线，质量可控
- iOS 签名 / Android WebView 碎片化成本推迟
- S3/PG 仅保留 trait 边界，不写适配代码

### 消极 / 需关注

- 移动端用户推迟；需在架构评审时持续检查"不锁死"承诺

## 备选方案

| 方案 | 结论 | 原因 |
| :--- | :--- | :--- |
| 移动端首发 | 否 | 交付成本与 ONNX 移动端性能不确定性高 |
| 桌面 + 移动端同步 | 否 | 稀释核心体验，违反垂直切片节奏 |
