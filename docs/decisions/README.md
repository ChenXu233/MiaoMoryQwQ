## 流程

1. 判断是否需要 ADR：影响架构/依赖/范围/流程/性能策略 → 需要；个人风格 → 不需要。
2. 复制 `_template.md`，编号取当前最大值 +1。
3. 起草为 `Proposed`，供项目所有者评审。
4. 批准后改为 `Accepted`，并**在本索引登记**。
5. 需修订时写新 ADR，旧 ADR 标记 `Superseded by ADR-NNNN`。
