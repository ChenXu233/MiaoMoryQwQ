## 1. 信息架构（UI 对齐原型 v6~v9，已实现）

- **APP 思维**：顶部无常驻 bar、无品牌字样；空态无标语（理解来自看到功能）
- **侧边栏**（桌面 ≥901px 常驻挤压式；窄屏 ≤900px 抽屉，右上汉堡圆钮呼出、遮罩/Esc/路由切换关闭）：brand-mark → 首页/照片库 → 文件夹区（计数 + 🟢在线/⚪离线/🔴丢失状态点 + 建索引徽标 + ＋导入）→ 底部左为齿轮设置，右为收起钮（2026-09-09 所有者裁定：设置不靠右；收起后左上角悬浮 brand 钮恢复，偏好持久化；窄屏抽屉保留关闭钮）
- **底部 Dock**（窄屏）：首页/照片库/设置（无侧边栏入口）
- **首页**：居中 logo + 大搜索框；回车提交 → 滑顶结果态；结果网格/列表带元数据（文件名/日期/文件夹/大小/命中徽标）；范围跟随侧栏所选文件夹（占位文案 + 结果头标注 + 切换即时刷新）
- **照片库**：时间线（默认，年份吸顶）/瀑布流切换；152px 定宽单元格恒定（开合/重排不缩放）；悬浮搜索胶囊（实时搜 + Ctrl K）；**索引状态可见**（2026-09-09 所有者指示）：未建索引的照片格右下角呼吸点，侧栏文件夹行显示「建索引中 N」，搜索结果头/空结果提示附带待索引计数
- **设置**：外观（主题即时生效/语言 LATER）、语义模型（状态/进度/重试）、数据位置、来源文件夹（重检/重指）、存储占用、失败文件
- 延迟预算沿用 `ux/latency-budget.md`；搜索耗时在结果头实时显示

## 2. 来源文件夹（工作区）与离线（迁移 v4）

- `folders` 表：path/label/channel('local'，预留扩展)/status/added_at；资产 `folder_id` 归属；同工作区 (folder_id, sha256) 唯一，**跨工作区同内容各自成条**
- 缩略图按 sha 内容寻址共享，删除按引用计数回收；**缩略图与照片强绑定不逐出，格式 JPEG q80 384px**（裁定 8/12）
- 状态机 `online/offline/missing`：被动标记（原图 `@error` 上报）+ 主动重检；无后台轮询
- **索引自足**：浏览/搜索只依赖索引库 + 缩略图；原文件仅在 Lightbox 解析
- **缩略图/原图永不混淆**：网格永远缩略图不逐张标注；Lightbox 在线角标「原图 · 大小 · 来自…」，离线显示缩略图 + 状态条「原件所在文件夹不在线：{路径}」+ 重新检查；missing → 重新指定位置（storage_key 前缀批量改写）

## 3. 导入与索引（后台任务，裁定 22/23）

- 导入 = 后台任务卡（**右下、可收纳**：展开为进度/ETA/暂停/停止/失败计数，收起为一行胶囊，点击展开；2026-09-09 所有者裁定移至右侧），完成广播 `mm-library-changed`（库/文件夹即时刷新）；部分失败右上通知 + 设置常驻清单
- **自动同步与自动索引**（2026-09-09 所有者指示）：已注册文件夹由 watcher 守护自动增量导入（规格 0001 §3.8/3.9）；导入完成即自动清嵌入队列（错峰），文件夹/照片格/搜索三处可见建索引进度；用户无需手动触发任何「建索引」操作
- IO 预取：预算 clamp(总内存/8, 256MB, 1GB)，批 ≤ 预算/2，解码线程数 ≈ 预算/96MB；全尺寸解码图即用即释（峰值 ≈ 1 张/线程）
- **索引永远解码原图**（裁定 23；HEIC 快路径仅限缩略图生成路径，`decode_photo` 嵌入入口禁用）
- 启动自动：检查模型缺失 → 自动下载（防重入）→ 装载全部可装配索引 → worker 按索引清队列；同内容跨工作区复制向量免二次推理
- 模型未就绪时搜索明示「语义模型正在准备」而非「没有找到」

## 4. 可插拔索引（ADR-0013，迁移 v5）

- `index_meta` 注册表（slug/display/model/dim/vec_table/status）；`Indexer` 端口（mm-core）；
  新索引运行时建独立 vec0 表；向量 API 全部按 index_id 参数化；级联删除覆盖全部索引
- 检索：每套支持文本的索引各出一路 KNN + FTS 流 → `rrf_fuse_multi`（k=60）；模型缺失的索引自动缺席，不阻塞其余
- 占用可视化：设置 → 存储占用按索引展示条数与近似体积（count×dim×4）；清理功能按裁定暂不做

## 5. 删除（无回收站）

- 确认文案「只从 MiaoMory 移除，不会删除你的原文件」；删除 = 资产行 + 各索引向量 + FTS + 引用归零的缩略图文件
