# 体验 0005：混合检索融合

- 状态：已评审（所有者 2026-09-04 授权连续作业，视为批准冻结）
- 关联规格：`docs/spec/0005-hybrid-search.md`
- 最后更新：2026-09-04

## 1. 延迟预算（关键路径）

| 交互 | 预算 |
| :--- | :--- |
| 双流检索 + 融合（≤5 万向量） | P50 < 150ms / P95 < 500ms |
| 过滤器变更 → 结果刷新 | < 200ms |

## 2. 状态矩阵（体验视角）

- 排序理由徽标：`both` 不显示（默认最强）、`语义` / `文件名` 小字徽标；不使用裸技术词。
- 过滤器：年月下拉（来自库内年份集合）+ 类型切换（全部/照片）；变更即刷新，无提交按钮。

## 3. 文案

- 徽标：`语义` / `文件名`
- 过滤器占位："全部时间" / "全部类型"
- 单流降级："部分搜索通道暂不可用，结果可能不全。"

## 4. 键盘与无障碍

- 过滤器为原生 select，Tab 可达；结果区焦点循环；徽标有 aria-label（"命中来源：语义"）。

## 5. 测量方法

- tracing：`search.fuse`（融合耗时）、`search.fts`（FTS 查询耗时）；一次性人工验收回填 `latency-budget.md`。
