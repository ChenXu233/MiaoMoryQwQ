# 体验 0003：中文语义搜索

- 状态：已评审（所有者 2026-09-04 授权连续作业，视为批准冻结）
- 关联规格：`docs/spec/0003-search.md`
- 最后更新：2026-09-04

## 1. 延迟预算（关键路径）

| 交互 | 预算 |
| :--- | :--- |
| 输入反馈（防抖前回显） | < 100ms |
| 语义搜索首屏（≤5 万向量，P50/P95） | < 150ms / < 500ms |
| 文本编码（单 query） | < 50ms |
| 结果渲染（复用虚拟网格） | < 100ms |

## 2. 状态矩阵（体验视角）

- 防抖 150ms；输入过程中不触发搜索，回车立即触发。
- 结果页复用时间轴单元格；Lightbox 内 ←/→ 沿相似度序切换，Esc 回结果页。
- 部分索引提示条常驻可关闭；不打断结果浏览。
- 空结果：给出建议词（"试试更具体的词，比如『火锅』『雪山』"）。

## 3. 文案

- 占位符："搜索你的照片，比如：海边的日落"
- 离线态（模型缺失）："搜索功能需要先下载识别模型（约 200MB，仅一次）。" 按钮：「下载识别模型」
- 错误："搜索出了点问题，请重试。"
- 空结果："没有找到相关照片。" + 建议词。

## 4. 键盘与无障碍

- Ctrl/Cmd+K 聚焦搜索框（P1 先预留快捷键，P3 打磨全局命令面板）。
- 结果焦点可达；Enter 打开 Lightbox；Esc 清空搜索回到时间轴。

## 5. 测量方法

- tracing span：`search.encode_text` / `search.knn` / `search.render`；一次性人工验收回填 `latency-budget.md`。
- 检索质量：所有者本人照片集 + 自拟中文查询词逐条验收（ADR-0010）；不达标触发 ADR-0006 正式基准。
