# 体验 0006：数据位置与口袋式布局（设置）

- 状态：已评审（随 ADR-0011 / spec 0006 一并冻结）
- 关联规格：`docs/spec/0006-settings.md`
- 最后更新：2026-09-06

## 1. 延迟预算（关键路径）

| 交互 | 预算 |
| :--- | :--- |
| 设置对话框打开 | < 100ms（数据同步返回，无加载态） |
| 「打开数据文件夹」反馈 | < 200ms 内有按下反馈；资源管理器弹出时间不计 |
| 「更改数据位置」写入 config | < 100ms（小文件写），完成后立即出现"重启后生效"提示 |

## 2. 状态矩阵（体验视角）

- 口袋模式徽标用 `text-accent` 强调，标准模式用 `text-muted`——口袋是产品卖点，视觉上"被祝贺"；标准模式平实呈现不制造焦虑。
- 更改成功 = 行内提示"重启后生效"，同时按钮进入禁用态防止重复更改；不弹模态打断。
- 错误 = 行内红字，保持用户已选路径可见，便于排查权限问题。

## 3. 文案

| 场景 | 文案 |
| :--- | :--- |
| 模式徽标（口袋） | 「口袋模式 · 数据随应用携带」 |
| 模式徽标（标准） | 「标准模式」 |
| 数据区说明 | 「所有数据都保存在这台电脑上，MiaoMory 不会上传任何内容。」 |
| 按钮 | 「打开数据文件夹」「更改数据位置…」 |
| 更改成功 | 「已记录新位置，重启 MiaoMory 后生效。」 |
| 目录不可写 | 「这个文件夹无法写入，请选择你有写入权限的位置。」 |
| 回退布局首提示 | 「数据保存在文档目录：{path}」 |

裸技术词零出现：不向用户展示"SQLite/WAL/向量"等词；路径展示完整但可折叠。

## 4. 键盘与无障碍

- 入口：标题栏齿轮按钮，`Tab` 可达，`Enter` 打开；对话框内焦点圈保持在浮层内。
- `Esc` 关闭对话框（全局浮层铁律）；关闭后焦点回到齿轮按钮。
- 徽标不止靠颜色区分（口袋模式带图标 + 文字），满足色弱可用。
- 路径文本 `select-text` 可复制；行内提示用 `role="status"` 播报。

## 5. 测量方法

- 开发版浮层观察：对话框打开耗时、config 写入耗时（tracing `info!` 记录布局解析结果与耗时）。
- 一次性人工验收（ADR-0004）：启动布局判定四种场景各一次（env / 标记 / 自动 / 回退），核对 `data_info` 与实际落盘一致；NSIS 安装→卸载→确认 `data\` 存活。
