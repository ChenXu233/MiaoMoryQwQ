## 1. 延迟预算（关键路径）

| 交互 | 预算 |
| :--- | :--- |
| 进入浏览态首屏渲染 | < 500ms |
| 滚动帧率 | 60fps（虚拟滚动，DOM 数量有界） |
| 缩略图可见 → 显示 | < 250ms（本地文件读取） |
| 点击缩略图 → Lightbox 出现 | < 200ms |
| Lightbox ←/→ 切换 | < 150ms（原图异步加载，先显示低清缩略图放大过渡） |

## 2. 状态矩阵（体验视角）

- 骨架屏：分页加载时新增区域显示灰色占位块，禁止 spinner。
- 缩略图渐显：加载完成 CSS opacity 过渡 120ms；不逐项动画。
- 年份吸顶：分组标题 sticky，滚动跨年时轻微位移过渡（≤150ms CSS）。

## 3. 文案

- 空态复用 0001。
- Lightbox 顶部："2023 · 6 月 12 日"（来自 taken_at，本地时区）。
- 删除确认："删除这条记录？只从 MiaoMory 移除，不会删除你的原文件。" 按钮：「删除」/「取消」。
- 原图缺失："原文件无法读取，可能已被移动或删除。"

## 4. 键盘与无障碍

- 网格：←/→/↑/↓ 移动焦点，Enter 打开 Lightbox。
- Lightbox：←/→ 切换、Esc 关闭、Space 切换 1:1、Delete 删除（需确认）；关闭后焦点回到来源缩略图。
- 所有可交互元素焦点环可见（2px accent outline）；对比度 AA。

## 5. 测量方法

- tracing：`browse.page_query`（分页查询耗时）、`thumb.serve`（缩略图读取）。
- 一次性人工验收：≥1,000 张库滚动流畅度、Lightbox 键盘全流程；回填 `latency-budget.md`。
