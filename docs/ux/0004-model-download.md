# 体验 0004：模型下载

- 状态：已评审（2026-09-06 随 spec 0004 修订：启动自动下载 + 文案纠正）
- 关联规格：`docs/spec/0004-model-download.md`
- 最后更新：2026-09-06

## 1. 延迟预算（关键路径）

| 交互 | 预算 |
| :--- | :--- |
| 启动 → 自动下载开始（进度出现） | < 2s |
| 手动点击下载 → 进度出现 | < 500ms |
| 进度事件节流 | ≥100ms |
| 校验阶段反馈 | 校验期间显示"正在校验文件"（不误判为卡死） |

## 2. 状态矩阵（体验视角）

- **启动即自动下载**：进度在空态与浏览态都全局可见，不要求用户先点搜索（导入索引与搜索共用这套模型，从第一次导入就是必需品）。
- 进度 = 总字节 + 已接收字节 + 速率；多文件合并为一个总进度条，当前文件名单独一行。
- 断点续传文案必须出现（"已下载部分不会丢失"），这是与用户的核心约定。
- 暂停：关闭页面不中断下载（后台继续）；显式暂停按钮 P2 先不做（场景弱）。

## 3. 文案

- 引导（重试/手动入口）："导入索引与搜索需要一套中文图文语义模型（约 200MB，仅下载一次）。模型只在本机运行，照片不会上传。"
- 进行中："正在下载语义模型 128 / 200 MB（已下载部分不会丢失）"
- 校验："正在校验文件完整性…"
- 成功："模型就绪，试试搜索：海边的日落"
- 失败："下载失败：网络不可用。已下载的部分会保留，恢复网络后接着下。" 按钮：「重试」

## 4. 键盘与无障碍

- 下载按钮 Tab 可达；进度条 role=progressbar 带 aria 值；错误条 role=alert。

## 5. 测量方法

- tracing：`model.download`（每文件字节数/耗时/平均速率）；一次性人工验收记录真实下载时长回填 `latency-budget.md`。
