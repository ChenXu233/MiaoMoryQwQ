## 目标

| 指标 | 目标 | 说明 |
| :--- | :--- | :--- |
| 应用冷启动 | < 1s | 桌面三平台；不含首次模型下载 |

| 空闲内存 | < 200MB | 系统监控实测 |
| 安装包体积 | < 50MB | 含 ORT，待实测（可能上浮，白皮书 §6.1） |

## 验收方式（ADR-0004）

1. **一次性人工基准**：准备数据（项目所有者人工提供）→ 记录环境（OS/CPU/模型与版本/ORT 版本/sqlite-vec 版本）→ 测量 → 写入下方"实测记录" → 归档。
2. **CI 不跑**语义检索万级 bench 与模型速度检查；这些是升级时的一次性检查，不是每次 CI 反复做的。
3. **禁止**：常驻合成照片 bench；合成种子数据生成器（延后）。
