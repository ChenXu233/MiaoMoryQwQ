# 体验规格（ux）

- 状态：现行
- 维护者：项目所有者
- 最后更新：2026-09-04

本目录定义**体验质量**：好用与否。与 `docs/spec/` 同编号对应；编号规则见 `docs/spec/README.md`。

## 每份 UX 规格的固定章节

1. **延迟预算**：引用或细化 `latency-budget.md`（不重复定义总数，只标注本功能关键路径）。
2. **状态矩阵（体验视角）**：复用 spec 的七状态，补充微交互、动画、降级动作。
3. **文案**：关键状态的实际示例文案（行动导向，见下）。
4. **键盘与无障碍**：本功能的快捷键、焦点流转、Esc 行为、对比度。
5. **测量方法**：对应 tracing 指标与开发版性能浮层的观察点；一次性人工验收（ADR-0004）。

## 动效原则

- 默认 CSS transition；微交互 ≤150ms；不引入动效库。
- 列表滚动禁止逐项动画；骨架屏优先于 spinner；进度条始终显示绝对数量 + 剩余时间估算。
- 任何超过 500ms 的操作必须有可见反馈（白皮书 §1.3）。

## 文案规范

- 中文，行动导向："选择照片文件夹"，而非"请点击此处"。
- 用户不可见的裸技术词（哈希/向量/WAL/sqlite）一律不出现在 UI。
- 错误文案 = 发生了什么 + 用户能做什么 +（仅 troubleshooting 场景）错误码。
- 全局文案集中在 token/文案文件，禁止散落硬编码。

## 键盘与无障碍最低线

- 全部功能键盘可达；焦点可见；Esc 可关闭一切浮层；对比度 WCAG AA。
- Lightbox：← / → 切换，Esc 关闭，Space 缩放开关。
- 搜索：Ctrl/Cmd+K 聚焦；结果列表上下键导航 + Enter 打开。
