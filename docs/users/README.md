## 写作规范

- 每页一个任务；用"你"称呼读者。
- **禁止裸技术词**：哈希、向量、SQLite、WAL 等不得出现；确需解释时用类比。
- 截图规范：放各页同目录 `assets/`；标注应用版本；隐私内容（人名/位置）打码。
- 每篇标注适用的最小应用版本。

## 隐私文档的固定承诺（白皮书 §5.5）

不上报 · 不联网（模型下载除外）· GPS 默认不入库 · 数据仅存本地工作区 · 索引库可随时用第三方工具打开。

## 上线门槛

alpha 至少提供 `quickstart.md` + `privacy.md`；beta 补齐其余。
