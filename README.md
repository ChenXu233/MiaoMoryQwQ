# MiaoMory

个人媒体语义索引引擎 —— 只索引、不存储的"胶水/感知引擎"。用一句中文找到你的照片。

> **当前阶段：规范先行**（2026-09）。文档体系已建立，代码尚未初始化。

## 它解决什么

- **语义检索**：用中文一句话找媒体（"去年海边的日落"），而非靠文件夹翻找
- **数据不锁定**：索引库是可剥落的标准格式（SQLite），软件可被替代，你的数据永远属于你
- **双击即用**：单二进制、<1s 启动、零配置，不需要 Docker 和命令行

## 技术栈速览

| 层 | 选型 |
| :--- | :--- |
| 桌面壳 | Tauri v2（桌面优先，移动端 LATER） |
| 核心 | Rust workspace，单向依赖（ADR-0005） |
| 推理 | ONNX Runtime（ort）+ 中文图文模型（ADR-0006 选型中） |
| 向量索引 | sqlite-vec（ADR-0002） |
| 存储 | SQLite（WAL）+ 缩略图目录；S3/PG 为 LATER |
| UI | React + TypeScript + Tailwind |
| 契约 | specta：Rust 命令 → TS 类型生成 |

## MVP 范围（一句话）

**桌面 + 照片 + 中文语义搜索**；移动端、S3、人脸、插件、音视频语义为 LATER。详见白皮书 §2 与 ADR-0003。
