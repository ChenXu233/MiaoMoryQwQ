# region-proto:区域级语义索引 Python 原型

验证构想(2026-09-11 与所有者讨论):**自然区域分离 → 区域 embedding → 跨库全局聚类(自然语义类)→ 区域级晚交互检索** 的前两步半,拿 F:\相册 229 张真实照片离线验证簇质量。

## 管线

```
照片 → MobileSAM 全图分割(自然区域 mask)
     → 区域裁剪(bbox+12% padding)
     → Chinese-CLIP ViT-B/16 int8 图像塔(复用 .devdata/models,零训练)
     → 512 维区域向量(L2 归一)→ regions.npz
     → 全局 k-means(k=32)→ 簇可视化拼图 + 统计
```

对应文献:Segment Anything(ICCV 2023)/ RegionCLIP(CVPR 2022)/ ViLD(ICLR 2022)/
SlotCon(NeurIPS 2022)/ ColPali late interaction。缺口 = 增量聚类下的簇稳定性(组合新颖点)。

## 双空间共识检索评估(2026-09-11,consensus_eval.py):频域候选池 + 语义代表

所有者修正方案:频域粗簇(64,近零成本)= 候选池,每簇只编码 3 个分散语义代表
(CLIP 调用 5142 → **192,−96%**),查询走「代表 MaxSim → 命中簇 → 簇内结构精排」。
leave-one-out 同语义簇命中率:

| 方案 | CLIP 调用 | hit@10 | hit@50 |
|---|---|---|---|
| 基准:全量 CLIP KNN | 5142 | 0.653 | 0.529 |
| **PCA-64 签名 KNN** | 5142(下游全便宜) | **0.639** | **0.553(反超)** |
| 频域粗簇 + 3 代表 | **192(−96%)** | 0.147 | 0.110 |

判读:
1. **PCA-64 无损确认**:hit@10 仅 −1.4%,hit@50 反超(去噪)——语义压缩刀锋定案;
2. **频域候选池单独使用召回崩塌**(0.147,损失 77% 换 96% 成本):结构簇语义不纯,
   代表 MaxSim 命中的簇常不含正确语义;结构特征(FFT+布局)与语义相关性不足是根因;
3. **频域岗位定案**:同场景去重/连拍分组/实例近邻(它测的正是这些),以及展示层
   「结构分组 + CLIP 世界知识自动命名」(zero-shot 簇命名)——不承担语义检索路由;
4. 后续可试:粗池特征换 DINO 浅层 patch 特征(与 CLIP 相关性更高,预期召回居中;
   ColPali 社区做法),届时候选池方案可重新评估。

**当前定案管线**:SAM 区域 → CLIP 编码(NIOU 去重后)→ PCA-64 签名(聚类/存储/检索)
→ 时空调制在线 DP-means(原型空间)→ MaxSim 检索;频域负责去重与结构分组。

## EXIF 时空调制实验(2026-09-11,dpmeans_spatio_exif.py)

EXIF 实测:229 张**全部有 DateTimeOriginal**(vivo Y66L);**143 张(62%)有 GPS 经纬度**
(纬度 28.90~29.09,同城 ~21km 跨度;GPS IFD 有海拔参考但部分无坐标)。

所有者 2×2 矩阵实现(Δt=EXIF 时间差,Δs=GPS haversine,与上一张比较):
- 连拍 Δt<5min 且 Δs<200m → τ×0.5;久留 Δt≥2h 且 Δs<200m → τ×0.9
- 移动 Δt<2h 且 Δs≥1km → τ×1.3;篇章 Δt>14d 且 Δs≥5km → 完全新增
- GPS 缺失对退化为时间规则(Δt<5min ×0.5;>60d 篇章)

初版结果(τ_base=0.24,未标定):
| 变体 | K | 单例率 | NMI vs 语义 |
|---|---|---|---|
| fixed(无调制) | 63 | 41% | 0.310 |
| spatio(EXIF 调制) | 385 | 51% | 0.384 |

判读:
1. **方向验证**:时空调制让 K 响应时空覆盖(63→385),且 NMI 反升(0.31→0.384)
   ——调制开出的新簇多是真实场景切换,不是垃圾;
2. **参数未标定**:×1.3 移动乘数在这批数据上过开簇(单例 51%)。三个待标定项:
   τ_base 上调区间(在线 DP 碎片特性)、调制乘数收敛(1.3→~1.15)、
   新簇"存活确认"机制(2 张内复现才转正,否则并入最近原型);
3. NMI 对比需控制 K 相近(385 vs 63 不可直接比)——标定时做 τ_base 扫描使两变体
   K 对齐再比 NMI/ARI。
下轮:τ_base × 乘数 网格扫描(自动),目标 单例率<25% 且 NMI≥fixed 同 K 水平。

## 分层映射实验(2026-09-11,structure_eval.py):「最贵的语义放最少的刀锋」

所有者构想:先在便宜空间(傅里叶类结构特征)聚类,再映射回语义空间,CLIP 只标代表。
实验裁决(5142 区域,结构特征 = FFT 8×8 幅度谱 + 4×4 布局 + 颜色矩,86 维):

| 映射空间 | vs 512 维语义聚类的 NMI / 纯度 |
|---|---|
| **频域结构特征 k=64** | **0.183 / 0.178(≈随机 0.056)——否决** |
| CLIP 自身 k=64 细分(上限参考) | 0.697 / 0.725 |
| **PCA 64 维(语义低秩签名)** | **0.807 / 0.827(压缩 8 倍,去噪反升)** |
| PCA 32 维 | 0.718 / 0.686(压缩 16 倍) |
| PCA 64 维 + 1bit 符号化 | 0.532 / 0.519(可做检索预过滤,不宜聚类) |

**结论**:结构与语义近乎正交(NMI 0.18)——「频域聚类→映射语义」朴素路线被数据否决;
分层的正确刀锋是**语义向量的低秩压缩**:CLIP 编码一次后,聚类/存储/检索全部在
PCA-64 签名上做(便宜 8 倍、纯度反而 0.83)。CLIP 调用次数的削减靠重叠 mask
NIOU 合并(重复区域共享 embedding)+ 惰性编码(簇被命中才标注语义)。
频域特征的正确位置:同场景去重/连拍分组(它测量的"语义无关的结构相似"正是去重所需)。

## 增量聚类实验(2026-09-11,dpmeans_online.py)

**在线 DP-means**(距最近原型 1-cos > τ → 诞生新原型;否则加权均值漂移 1/count)
按拍摄序回放 5142 区域,τ 扫描:

| τ | 最终 K | top1 簇占比 | 单例簇 |
|---|---|---|---|
| 0.18 | 219 | 16% | **101**(过碎) |
| 0.22 | 85 | 26% | 34 |
| 0.26 | 46 | 27% | 16 |
| 0.30 | 25 | **45%**(过吞) | 12 |
| 0.35 | 17 | 65% | 8 |

**K(N) 曲线形状(关键发现)**:不是平滑 log N,而是**"平台 + 跳跃"的阶梯**——
平稳生活期原型几乎不增(τ=0.30 时 15 个簇维持了 100 张),生活变化期(2024 段)
一批新语义类集中诞生。U·log N 是长期平均的粗近似(rmse 14~17%),机制上
**K(N) 由生活事件驱动、τ 是唯一旋钮**(所有者的 U 即由此而来)。

设计推论:
1. 在线生灭 + 周期重排的混合结构正好匹配阶梯动态:跳跃期在线准入快速建簇,平台期零漂移
2. 纯在线必然产碎片(τ=0.18 时 50% 簇是单例)——**衰退合并(低权重老原型并入最近邻)
   与周期 mini-batch 重排是必需件**,不是可选项
3. 推荐工作点 τ≈0.22~0.26(余弦归簇门限 0.74~0.78),K 随库增长自然上行
